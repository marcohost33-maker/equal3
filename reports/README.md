# Reports (historical, unchanged)

Per-round documents as delivered, in their original language (German or English). They are kept
byte-identical; later knowledge is added in [`../docs/`](../docs/), never here.

| Folder | Content |
|---|---|
| `audits/` | audit report of every round, 2026-10-17 to 2026-10-25 — overview in [docs/AUDIT_HISTORY.md](../docs/AUDIT_HISTORY.md) |
| `readmes/` | per-version READMEs; `BUNDLE_ROOT_README.md` is the bundle's root README (still says v0.7.8) |
| `roadmaps/` | per-version roadmaps; current summary in [docs/ROADMAP.md](../docs/ROADMAP.md) |
| `release-gates/` | per-version release-gate JSON; every decision is NO_GO |
| `transfer/` | compliance (Swiss FADP) and CodeFactory transfer notes |
| `misc/` | environment records, UID isolation design (v0.7.9), test summary (v0.7.6) |

Transfer notes name other internal projects as reuse candidates; they state that those projects
were not re-checked and that any transfer requires a separate review in the target repository.
